ENTERPRISE PROJECT / 01

Centralized security posture & public-access governance

S3RDSAWS ConfigWAF / ShieldFirewall ManagerCloudTrail

Challenge

Review public exposure and security-control status consistently across 200+ AWS accounts instead of relying on isolated account checks.

Delivered scope

  • Automated S3 public/private access reporting in a centralized dashboard.
  • RDS accessibility checks, public-access standards and exception reporting.
  • WAF and Shield Advanced enablement-status visibility.
  • Firewall Manager security-group content audit status, CloudTrail log-file validation status and EC2 public-IP exceptions.

Operational value

Consolidated evidence helps security teams and account owners identify exceptions and prioritize remediation.

Scope and evidence

Control-status reporting does not establish that every resource is protected or completely isolated from public networks.

Source: Pavan’s professional portfolio

ENTERPRISE PROJECT / 02

AWS Tagging Governance & Reporting Automation

Account taggingResource taggingReporting automationCost allocationOwnership

Challenge

Identify inconsistent tagging and ownership gaps across 200+ accounts so governance and cost-allocation reviews use comparable evidence.

Delivered scope

  • Account tagging governance: compare account tags with the organization’s defined standards and report exceptions.
  • Resource tagging compliance reporting: classify standard, non-standard or inconsistent tags, and untagged resources.
  • Ownership and cost-allocation review: provide tagging evidence for accountable ownership and showback.
  • Centralized exception reporting: make account-level gaps visible for owner follow-up.

Operational value

Actionable tagging evidence supports account-owner remediation and provides a stronger foundation for governance and showback.

Scope and evidence

Reporting is distinct from automatic enforcement. Internal tag keys, approved values and compliance percentages are not disclosed.

Source: Pavan’s professional portfolio

ENTERPRISE PROJECT / 03

Backup-first unattached EBS cleanup

Amazon EBSBackup-first workflowAutomationAmazon SNS

Challenge

Identify unattached storage across the AWS estate and support consistent cleanup without assuming every detached volume is safe to delete.

Delivered scope

  • Detection of unattached EBS volumes across the multi-account environment.
  • Backups taken before deletion.
  • Automated deletion of eligible unattached volumes.
  • SNS reports covering actions and status.

Operational value

Backup-first handling supports storage hygiene, operational accountability and cost-management reviews. No unverified savings figures are claimed.

Scope and evidence

Exact production eligibility criteria, retention periods and approval settings are not published. Backup-completion checks and rechecking attachment are safe design considerations, not independently verified details of the deployed workflow.

Source: Pavan’s professional portfolio

PROJECT 05 · AWS GOVERNANCE · SECURITY · FINOPS · AUTOMATION

AWS RDS Governance & Health Monitoring

Status: Architecture & Implementation Planning

The architecture is designed; the capabilities below are proposed. Implementation and measured outcomes are pending.

Project overview

Designed a centralized monitoring architecture to assess AWS RDS resources across multiple AWS accounts, using automated data collection and governance reporting.

Proposed architecture

  1. AWS member accounts and cross-account IAM roles
  2. EventBridge scheduling and Python Lambda data collection
  3. Centralized Amazon S3 report storage
  4. Python API
  5. React dashboard

Planned capabilities

  • Centralized RDS inventory and configuration reporting.
  • Security and compliance checks for encryption, backups, public access and deletion protection.
  • Database performance analysis using CloudWatch metrics.
  • Cost optimization insights for underutilized RDS instances and old snapshots.
  • Database engine end-of-support tracking and upgrade recommendations.
  • Account-, Region- and environment-level dashboard filtering.
  • Ownership-based alerts and remediation recommendations.

Technologies

AWS Organizations, Amazon RDS, AWS Lambda, Python, Boto3, Amazon EventBridge, Amazon CloudWatch, Amazon S3 and React.

Expected outcome

Centralized RDS visibility, reduced manual auditing, and actionable security, operational and cost optimization recommendations.
